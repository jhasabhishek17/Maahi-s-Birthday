# Maahi Birthday World — Frontend

A cozy, interactive birthday website built with React + Vite + Tailwind CSS + Framer Motion.

## Quick Start

```bash
npm install
npm run dev
```

Runs at http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Customization

- **Birthday message:** `src/pages/BirthdayLetter.jsx`
- **Jokes:** `src/data/jokes.js`
- **Compliments:** `src/data/compliments.js`
- **Birthday wishes:** `src/data/wishes.js`
- **Bouquet/gift options:** `src/data/giftOptions.js`
- **Teddy character:** `src/components/teddy/TeddySVG.jsx`
- **Color palette:** `tailwind.config.js`
